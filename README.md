# slicedearth

I build privacy-conscious tools for domain intelligence, OSINT, and focused user experiences.

## Featured work

### [WHOISleuth](https://github.com/slicedearth/whoisleuth)

A domain-intelligence and brand-protection console combining WHOIS, RDAP, DNS, Certificate Transparency, web evidence, and analyst case workflows.

- TypeScript, Svelte, and Node.js
- Authority-aware registry analysis and separately attributed evidence
- Bounded, SSRF-safe network collection and defensive parsing
- Explainable findings, accessible interfaces, and comprehensive automated tests

[Live application](https://whoisleuth.com) | [Engineering case study](https://github.com/slicedearth/whoisleuth/blob/main/docs/engineering-case-study.md)

### [Forty Life](https://github.com/slicedearth/forty-life)

A touch-friendly, seating-aware life counter built for a shared tabletop device.

- Svelte 5 and TypeScript
- Responsive two-to-six-player layouts
- Accessible controls, local persistence, and live card-art integration

## Engineering focus
